3. Custom data plan (obrigatório para o webhook)

O site já acrescenta isto aos links de checkout. Confirma que o URL final (ou o que colares no catálogo + o JS) inclui:

Mensal: https://studio9medical.lemonsqueezy.com/checkout/buy/VARIANT_UUID_MENSAL?embed=1&checkout[custom][plan]=subscription_monthly Anual: https://studio9medical.lemonsqueezy.com/checkout/buy/VARIANT_UUID_ANUAL?embed=1&checkout[custom][plan]=subscription_annual

No webhook, isto chega em meta.custom_data.plan. Sem isto, o sistema tenta adivinhar pelo intervalo de facturação ou pelo mapa subscriptionVariants.

4. Colar no packages/catalog.json

Preenche estes campos (substitui os UUIDs reais):

"subscription": { "enabled": true, "id": "studio9-pass", "monthly": { "plan": "subscription_monthly", "priceUsd": 14.99, "checkoutUrl": "https://studio9medical.lemonsqueezy.com/checkout/buy/UUID_MENSAL?embed=1" }, "annual": { "plan": "subscription_annual", "priceUsd": 99, "checkoutUrl": "https://studio9medical.lemonsqueezy.com/checkout/buy/UUID_ANUAL?embed=1", "equivalentMonthlyUsd": 8.25 } }, "lemonSqueezy": { "subscriptionVariants": { "UUID_MENSAL": "subscription_monthly", "UUID_ANUAL": "subscription_annual" } }
Nota: o mapa fiável é subscriptionVariants (variant UUID → plan). O JS do site acrescenta checkout[custom][plan]=… automaticamente a partir de monthly.plan / annual.plan. Não uses productsByName para o Pass (esse mapa é só para módulos one-time → package_id).

5. Webhooks a activar no Lemon Squeezy

Settings → Webhooks → o endpoint actual do site (o mesmo de order_created), e garante estes eventos:

  • order_created (já tinhas — manter)
  • subscription_created
  • subscription_updated
  • subscription_payment_success
  • subscription_resumed
  • subscription_cancelled
  • subscription_expired
  • subscription_payment_failed

Com Pass activo → o webhook concede todos os módulos pagos e grava o registo da subscrição (renovação, portal Lemon). Cancelamento mantém o acesso até ends_at; só subscription_expired corta de imediato. Na conta aparece badge, data e «Gerir subscrição».

6. Teste (modo Test mode do LS)

  1. Abrir studio9medical.com/precos/#precos — o botão do Pass deve dizer Start monthly Pass (já não “Avisem-me…”)
  2. Checkout mensal com cartão de teste LS
  3. Entrar em /conta/ com Google — mesmo email do checkout
  4. Confirmar que vários módulos pagos aparecem com acesso
  5. Repetir com variant anual (opcional)
  6. Cancelar no portal do cliente LS → confirmar que o acesso deixa de estar activo após o webhook
